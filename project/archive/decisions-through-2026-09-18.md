# Decisions archive — the visual redesign, Ikigai, and the rules that were promoted

**Split out of `projectRoadmap.md`'s decisions log on 2026-09-22.** Two kinds of row are here, and the
distinction is the whole reason the split happened.

**Settled feature decisions (18).** Calls about screens, packages and pipeline technique whose features have
shipped — the cork texture, the trophy glyph, `TrackDetailScreen`, the tap-bug diagnosis, WP23's half
sign-off. They were true when made and are now history.

**Rulings that became rules (13), which did *not* stop applying.** A dated table prunes by date, and a rule
never expires — so the table could only either bury them or never be pruned. **Each one now lives in the file
that is actually loaded at session start**, and is archived here only because it has a home:

| Ruling | Now lives in |
|---|---|
| A suggested model is a recommendation; Manager flags disagreement before starting | `agents/architect.md` |
| A named fix or constant is a hypothesis, not a specification | `agents/architect.md` |
| A handoff cites a commit, not a file location | `agents/architect.md` |
| A status row states merge state as observed, never as expected | `agents/architect.md` |
| Device gates split by question type, not by instrument *(and the amendment that corrected it)* | `agents/architect.md` |
| A criterion phrased as an observation is met by an observation | `agents/architect.md` |
| A register entry must be verified before a handoff cites it | `agents/architect.md` |
| Mutation-check two candidate fixes as separate reversions, not one | `agents/manager.md` |
| Pair a checker trained for clean output with a check that does not share its bias | `agents/pipeline-manager.md` |
| Image selection is not delegable to a machine | `agents/pipeline-manager.md` |
| A check's name says which of several conditions it covers | `agents/pipeline-manager.md` |
| A reader may re-open a finished Leaf, but re-reading counts for nothing | `project/PRODUCT.md` |
